## Featured Projects

### CampusFix

Campus facility reporting app with role-based workflows for students, technicians, and administrators. Its Express API supports reporting and follow-up, with Prisma models and JWT authentication.

**Tech:** Node.js, Express.js, Prisma, MySQL, JWT<br>
**Repository:** [mhmdiqb/campusFix](https://github.com/mhmdiqb/campusFix)

### Event Ticketing API
